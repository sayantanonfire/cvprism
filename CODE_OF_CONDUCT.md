# Code of conduct

cvprism is built for people at every career stage and from every discipline. We want this project to feel welcoming to all of them.

- **Be respectful.** Critique ideas and code, never people. Assume good intent.
- **Be inclusive.** Harassment, discrimination or personal attacks of any kind are not tolerated, in any project space.
- **Protect privacy.** Never post anyone's CV, career data or personal details in issues or pull requests, including your own real vault. Use synthetic examples.
- **Be patient with newcomers.** A first-time contributor's role profile is as welcome as a new sync adapter.

Report unacceptable behaviour privately to the maintainer through GitHub (Security → Report a vulnerability works for sensitive reports too). Maintainers may remove content or block participants who break these rules.
